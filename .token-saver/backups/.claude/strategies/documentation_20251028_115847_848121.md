# Application Documentation

- markdown files should be placed in the docs/ directory per the @docs/README.md guidance
- It should be user-centric, seeking not only a great intuitive user experience but also user delight.
- Documentation should be well organized.
- It should be regularly updated after any relevant changes.
- Acronyms should be defined first and then can be used.
  - Definitions should follow this pattern "Full Term Text (FTT)" where FTT is the acronym for whatever the "Full Term Text" is.
