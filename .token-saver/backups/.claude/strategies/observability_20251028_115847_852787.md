# Observability

- Logging should be used profusely, but not inappropriately
- Performance matters, we should be able to
  - estimate expected performance for functionality prior to starting development
  - if the functionality exists we should baseline its performance before starting work
  - after functionality is successfully delivered we measure performance against the baseline every time.
- Peformance should always be in a transparent and balanced conversation with the cost of resources when developing in the cloud.
  - When discussing approaches to architecture or implementation cloud cost should be discussed explicitly.
