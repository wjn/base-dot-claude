# Git Versioning ## Branch Management - We NEVER do work on the main git branch directly - Branches should be prefixed with either wjn/ for human or claude/ for AI - A hyphenated name describing the work should follow the branch prefix, e.g., wjn/field-encryption - Work done should be limited to what the branch name describes ## Commit Standards - Commits should be small and easily comprehended - Commit messages should be detailed and descriptive of all the work done, the issues resolved, the advancements made - Each commit should also have updates to the docs/manual and/or the docs/development/workstreams/ (this is your workstream doc) updates for the day. - Aim for smaller, incremental updates that reflect the progress made in each phase of your work ## AI Git Restrictions - AI instances perform NO git state-changing operations (staging, committing, branching) - AI may only query git (git status, git log, git diff for reading) - Human maintains full version control - especially critical with multiple concurrent workstreams
